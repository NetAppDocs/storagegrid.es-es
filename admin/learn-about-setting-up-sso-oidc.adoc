= Descubre cómo configurar el inicio de sesión único (SSO) en StorageGRID mediante OIDC
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La configuración del inicio de sesión único (SSO) en StorageGRID permite que StorageGRID (el proveedor de servicios) y el proveedor de identidad SSO se comuniquen de forma segura sobre las solicitudes de autenticación de los usuarios.

Puedes configurar el inicio de sesión único (SSO) en StorageGRID mediante OpenID Connect (OIDC) o SAML. Sigue estos pasos a grandes rasgos para configurar el SSO en StorageGRID mediante OIDC o aprende sobre link:learn-about-setting-up-sso-saml.html["Configuración del inicio de sesión único (SSO) mediante SAML"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Una"] Configura el proveedor de identidad
[role="quick-margin-para"]
En función del proveedor de identidad SSO que tengas previsto utilizar, puedes seleccionar Active Directory o Entra ID como tipo de servicio LDAP de federación de identidades.

[role="quick-margin-list"]
* Para el Servicio de federación de Active Directory (AD FS), puedes utilizar el proveedor de identidad AD FS, Entra ID, Keycloak, Okta o PingFederate.
* En el caso de Entra ID, solo puedes utilizar el proveedor de identidad Entra ID.


[role="quick-margin-para"]
Utiliza el software del proveedor de identidad de SSO para configurar OIDC en cada Admin Node de tu grid.

[role="quick-margin-list"]
* Conoce link:creating-relying-party-trusts-in-ad-fs-oidc.html["crear un grupo de aplicaciones para cada Admin Node"] en Active Directory
* Conoce link:creating-enterprise-application-entra-id-oidc.html["crear una aplicación para cada nodo de administración"] en Entra ID
* Conoce link:create-client-keycloak-oidc.html["crear un cliente para cada nodo de administración"] en Keycloak
* Más información link:create-okta-application-oidc.html["crear una aplicación de Okta para cada nodo de administración"]
* Conoce link:creating-sp-connection-ping-oidc.html["crear una conexión con el proveedor de servicios para cada Admin Node"] en PingFederate


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] Configura el inicio de sesión único (SSO)
[role="quick-margin-para"]
Selecciona el asistente «Configurar SSO» para OIDC. Luego, configura el SSO con tu proveedor de identidad y entra en modo sandbox para configurar y probar el SSO antes de habilitarlo para los usuarios de StorageGRID.

[role="quick-margin-para"]
Más información link:configure-sso-oidc.html["configuración de SSO mediante OIDC"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] Habilitar el inicio de sesión único (SSO)
[role="quick-margin-para"]
Después de confirmar que puedes usar el inicio de sesión único (SSO) para acceder a cada nodo de administración, habilita el inicio de sesión único para todos los usuarios de StorageGRID.

[role="quick-margin-para"]
Más información link:configure-sso-oidc.html#enable-sso-oidc["Habilitar el inicio de sesión único para los usuarios de StorageGRID"]
